## Aragrow Ollama LLM Integration Plugin

**URL:** https://aragrow.me/wp-plugins/aragrow-ollama-llm-integration-plugin/
**Published:** February 28, 2025
**Author:** David Arago

WordPress plugin that connects WordPress to a remote Ollama LLM instance:
- Configure your Ollama endpoint and API key in WordPress admin
- Connect to any Ollama-compatible model (LLaMA, Mistral, etc.)
- Use the `query_ollama()` function in themes/plugins to call the LLM
- Powers AI content generation, automation, and advanced features in WordPress
- API keys stored securely, not exposed in front-end requests
- Setup: WP Admin > Ollama LLM > enter Endpoint, Model Name, API Key > Save
