## 1. Aragrow – Ollama LLM Integration Plugin

**URL:** https://aragrow.me/wp-plugins/aragrow-ollama-llm-integration-plugin/
**Published:** February 28, 2025
**Author:** David Arago | **Word Count:** ~217

### Description
Connects WordPress to a remote Ollama large language model server, enabling AI-powered content generation, automation, and advanced AI functionalities within WordPress.

### Features
- Easy configuration via WordPress Admin panel
- Set your Ollama API endpoint, model name, and API key
- Secure API key storage (not exposed to front-end)
- WordPress-native settings interface
- Developer function `query_ollama()` for theme/plugin integration
- Returns AI-generated responses from your configured model

### Setup
1. Go to **WP Admin > Ollama LLM**
2. Enter Ollama API Endpoint
3. Enter Model Name (e.g., `llama3`, `mistral`)
4. Enter API Key
5. Click **Save Changes**
6. Use `query_ollama($prompt)` in your code to call the model

### Use Cases
- AI content generation inside WordPress
- Automated post summarization
- Intelligent chatbots on the site
- Custom AI-powered features in themes or plugins
